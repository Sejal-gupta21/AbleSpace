# AbleSpace Assessment

This repository contains the AbleSpace task management assessment built with Next.js (App Router), Tailwind CSS, and NestJS.

## Structure

- `frontend/` - Next.js app with Tailwind styling and theme support.
- `backend/` - NestJS API scaffold for task management.

## Getting Started

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run start:dev
```
